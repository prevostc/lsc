# Architecture Documents

These documents should record **decisions discovered by architecture reviews**, not guesses made in advance.

Expected outputs include, when established:

- `LANGUAGE_ARCHITECTURE.md`
- `SECURITY_MODEL.md`
- `PROOF_CHAIN.md`
- `MODULE_MAP.md`
- `TRUSTED_COMPUTING_BASE.md`

Keep them concise and decision-oriented.

Agents working on local tasks should rely on these contracts and module APIs rather than repeatedly reconstructing the whole system.
