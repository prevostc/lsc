# Decisions

Short dated records.

## 2026-09-07 — Keep S1 and S2 as two strata

S1 is the call-free fragment: forward completeness on a closed external
model (`calls := .none`). S2 is external calls: backward soundness on a
total CALL oracle (`CallsTotal`), with `Conforms` / `RX` / a binding
family. They stay separate. Collapsing them would need a dummy total
oracle on the call-free side, a completeness corollary from `yul_progress`
plus EVM determinism (`steps_halted_unique`), and interface-free
statements at empty bindings. Revisit when adding Core operations, not
before.

## 2026-09-07 — Generated per-contract bytecode glue (in progress)

Per-contract bytecode transport glue is generated by `lsc_contract`, and
side conditions are decidable. Contract authors write only the contract,
the Tx-level spec (`Inv`, `claim`, `Auth`, `holdings`), and Tx-level
proofs. They should not hand-write layout codecs or end-to-end transport
setup. **In progress:** example contracts still ship companion `*Compile*`
and `*EndToEnd*` modules; the macro does not yet emit that glue.

## 2026-09-07 — Dispatcher shape stays; readability via exported Yul/asm

The runtime dispatcher remains a Yul `switch` on `shr(224, calldataload(0))`
with inlined bodies and `default { revert(0,0) }`. Heimdall recovers none of
our selectors (0/4 Counter, 0/8 Token) because powdr's Yul→EVM lowering
emits `EQ; ISZERO; JUMPI` (jump on mismatch) for both `switch` and `if`,
while heimdall expects solc's `EQ; PUSH dest; JUMPI`. Experiments with
out-of-line Yul functions per entry and with an `if`-chain did not change
heimdall's result, grew the bytecode (+38 to +120 bytes), and would have
rewritten the whole dispatcher proof chain (`runtimeBlock_inv`,
`runtimeBlock_correct_*`, `yul_progress`). A solc-shaped dispatcher needs a
change to powdr's `compileSwitchCases` and its correctness proof — an
upstream TCB change, not a fork. For exploring generated code we export the
compiler's own artifacts instead: `out/<C>.runtime.yul`, `out/<C>.deploy.yul`
and `out/<C>.runtime.asm` from `scripts/export_bytecode.lean`.
